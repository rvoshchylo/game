# 08 — RUSTHEART v3 · Survivors (актуальний дизайн)

> Замінює v2 «Інженер». Причина: гравцю не було зрозуміло, що робити, і було нецікаво.
> v3 повторює перевірену формулу **Vampire Survivors / Brotato**: зрозуміло за 5 секунд, «ще один забіг».

## Суть за одне речення
Ти рухаєш робота, зброя стріляє сама; вбивай орди, збирай кристали, на кожному рівні обирай 1 з 3 покращень і протримайся 10 хвилин.

## Цикл
```
ЗАБІГ (10 хв)                                   МІЖ ЗАБІГАМИ
рух → автоатаки → кристали → рівень → 1 з 3   золото → постійні покращення
       ↑                              │        нові роботи / нова зброя (досягнення)
       └─ боси 5:00 / 8:00 → скриня → еволюція ─┘
```

## Системи (як у жанрі)
| Система | Реалізація |
|---|---|
| Керування | WASD/стрілки; на телефоні — плаваючий джойстик (тягни будь-де) |
| Зброя (6) | Удар бура, Іскровий заряд, Орбітальна пилка, Шокове поле, Мортира*, Лазерний спис* (*відкриваються досягненнями) |
| Пасивки (6) | Обшивка, Сервопривід, Магніт, Конденсатор, Підсилювач, Охолоджувач |
| Слоти | 4 зброї + 4 пасивки → вибір білду |
| Еволюції | зброя 5 рів. + своя пасивка → скриня боса дає супер-версію (6 штук, приховані в Колекції до відкриття) |
| Вороги | 7 типів, з'являються поступово щохвилини; рої на 2/4/7 хв; боси Циклоп (5:00) і Порожній Дзвін (8:00) |
| Предмети | кристали досвіду, монети, зілля, магніт, скриня боса |
| Мета-прогрес | 10 постійних покращень за золото, 4 роботи (золото або досягнення), рекорди |

## Баланс (бот-симуляція `npm run sim`)
Бот, що просто тікає по колу: перші забіги — загибель на 5–9 хв, з удачею — перемога; 250–800 золота за забіг → покращення купуються щоразу.

## Що далі
Більше зброї та еволюцій, друга карта, щоденний челендж, музика.
